# EasyPrice

Is a simple way to manage a price list on a single device or sync with other devices on the same local network

Easy price use a very basic security so its not recomended for big teams, many shops sharing the same price list or sensitive information

## Apps
* ###  Desktop
EasyPrice has a desktop version for Windows and Linux ready to deploy but the MacOS version needs to be compiled by the user
  The desktop app can be used individually, as a server or as a client for the same app running from other desktop device.

* ### Android
The app has an Android version only to use as a client for the desktop app running from other device to centralize the prices

## Features

* ### Multi-currency
Made for the Venezuelan market where the prices changes day on day you hace the option to change the exchange rate manually
and compare in real time in both currencies the diference when changing some product price.

* ### An easier way to calculate benefits
You don't need to calculate manually, the you tell the app what you paid for the products, the gain you want and the app gives you the sell price
